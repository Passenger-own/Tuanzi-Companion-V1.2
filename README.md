# 🐱 团子陪伴 Tuanzi Companion

一只住在你 Mac 里的 AI 伙伴——它认识你、陪你专注、在合适的时候出现。

---

## 这不是一个桌宠工具箱

团子是一只 **3D 毛绒猫咪**。大多数桌宠是一段等你点击的动画，而团子想回答的是另一个问题：**人和 AI Agent 到底该怎么相处。**

- 别的桌宠等你点击，团子会在合适的时候自己出现
- 别的桌宠每次打开都是新的，团子记得你说过什么、在忙什么
- 别的桌宠一天一个表情，团子有自己的作息——早上伸懒腰，下午犯困，深夜悄悄蜷到屏幕角落
- 别的桌宠不分场合地卖萌，团子懂分寸——你专注时它安静陪着，你深夜还在赶工它会说一句"别太辛苦"

它不是一个等你点击的工具，是一个住下来的伙伴。

## 走过的路

### V1.0 · 先把功能做全

最初的判断很直接：桌宠能做的事越多，价值越大。于是待办清单、计算器、记事本、快捷键面板、健康提醒全被塞进右键菜单，靠干净的菜单保证桌面视觉不被遮挡。

然后做了 17 份用户测试。SUS 71.5，高于行业基准 68，看起来是个不错的成绩。但有两个数字很刺眼：

- **59% 的用户找不到功能在哪**（10/17），新手期普遍迷茫
- **AI 对话满意度 3.4/5，是所有模块里最低的**

更关键的发现藏在访谈里：用户几乎从不通过一只猫打开计算器。工具集是"顺手加上的"，不是这个产品的差异化。

**判断：功能数量不是产品价值。真正要回答的问题是——用户为什么愿意让一只猫留在桌面上。**

### V1.1 · 让功能被找到

先修可发现性：悬停团子弹出浮动工具栏，配合 4 步新手引导，把高频操作从隐藏菜单里搬到明面上。

同时重做 AI 对话：流式输出降低等待感，12 轮摘要压缩让人设不会在长对话里漂移，三种人设可切换。

但这一轮真正有价值的收获不在功能表上。用户反馈里出现最多的字是"**陪**"——他们并不在意团子能算多复杂的数，他们在意的是，加班到深夜时桌面上有个活着的东西。

**判断：用户要的不是更多功能，是"被陪伴"的感觉。**

### V1.2 · 想清楚了，做减法

既然答案是陪伴，工具窗口就是噪音。

- **删掉全部独立工具窗口。** 效率能力融进对话——你说"帮我算一下 2380 乘 12"，说"截屏是哪个快捷键"，团子直接回答，不再弹一个计算器出来。
- **长期记忆。** 每次对话结束后，团子在后台安静提取关于你的关键信息：你的名字、最近在忙什么、偏好、待办，甚至"上周三凌晨两点你还在工作"这样的共同经历。下次聊天它会自然提起，而不是背记忆清单。
- **日间作息。** 团子开始有自己的生活节奏：9-11 点像刚睡醒一样伸懒腰，14-16 点趴着眯一会儿，23 点之后慢慢挪到屏幕角落蜷起来睡觉。不是围着你转。
- **无言陪伴。** 你专注时它不弹气泡、不打断，只是默默坐到光标旁边陪着你。

产品定位从"桌宠工具箱"，落到了"情感型 AI 伙伴"。

## 现在团子能做什么

### 💬 会聊天，而且记得你

三种人设可切换，流式输出让回复逐字上屏；聊满 12 轮自动做摘要压缩，长对话也不会人设漂移、答非所问。更重要的是长期记忆——它记得你在忙什么、你喜欢什么、你们一起加班到深夜的那些晚上。

AI 对话里直接问 Mac 快捷键、算数、让它"帮我记一下明天交报告"，它都会直接回答或存进记忆，不再弹独立窗口。

### 🌙 陪你专注，但不打扰

两档专注模式：轻度是侧躺陪你，深度是熟睡不打扰。开启后团子安静坐着，喝水提醒、活动提醒会静默排队，不在你进入状态时跳出来。你专注满 40 分钟，它会默默挪到你旁边坐着——不弹气泡，只是陪着。结束时它先伸个懒腰，像它也坐累了，再提醒你起来活动。

### 💧 日常的小互动

喂它喝水，它会咕噜咕噜地跟你道谢；按住它两秒摸摸头，它会眯起眼睛，头顶冒出一颗飘走的小爱心；拖着它走，它会身体倾斜、四肢耷拉，松手后晃一下站稳。这些都不留痕迹、不做记录，只是一只猫该有的反应。

### ⏰ 它会主动关心你

深夜还在工作，它会打个哈欠冒泡："好晚了呀，别太辛苦～"。太久没理它，它会发呆："你是不是把我忘了呀…"。坐久了，它会提醒你起来走两步。这些主动行为有频率上限、专注模式下自动降级——它懂分寸，不刷存在感。

## 技术栈

| 技术 | 用途 |
|---|---|
| Python 3.8+ | 运行环境 |
| PyQt5 | GUI 框架（无边框透明窗口 + 毛玻璃 UI） |
| QMediaPlayer / QMovie | 视频 / GIF 动画渲染 |
| requests | DeepSeek API 流式调用 |
| 本地 JSON | 记忆、对话、提醒、配置持久化 |

- **PyQt5 原生渲染，无 WebView**，常驻内存 25 MB 以内
- **DeepSeek API 流式对话**；记忆、对话摘要、配置全部存**本地 JSON**，仅当前上下文经 API 请求模型，**不做任何二次留存或分发**
- **GIF 预缩放直出渲染**（3D 素材预渲染为逐帧序列，按显示尺寸解码、命中同尺寸直接绘制，省掉每帧重采样），首屏加载快 80%+

## 怎么跑起来

```bash
git clone https://github.com/Passenger-own/tuanzi-companion.git
cd tuanzi-companion
pip install -r requirements.txt
python main.py
```

或者免装依赖：

```bash
bash run.sh
```

`run.sh` 会自动在 `~/Library/Application Support/桌面宠物/` 下创建虚拟环境并安装依赖，首次约 30 秒，之后秒开。启动日志：`~/Library/Application Support/桌面宠物/launch.log`。

**配置 API Key**（AI 对话功能需要）：

```bash
export DEEPSEEK_API_KEY="sk-你的DeepSeek密钥"
```

或首次运行后**右键团子 → API 配置** 填入。获取 API Key：<https://platform.deepseek.com/>

## 数据存储

所有用户数据保存在 `~/Library/Application Support/桌面宠物/data/`：

| 文件 | 内容 |
|---|---|
| `chat_history.json` | AI 对话历史 |
| `user_memory.json` | 团子的长期记忆 |
| `pet_config.json` | 宠物昵称、API 配置 |
| `reminder_state.json` | 提醒间隔与状态 |
| `onboarding.json` | 新手引导完成标记 |

记忆、对话、配置全部本地存储，不上传任何服务器。
