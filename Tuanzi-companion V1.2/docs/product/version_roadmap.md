# 迭代规划与版本管理

> 管理方法：P0/P1 分层需求优先级 + 「测试发现 → 决策迭代 → 复测验证」闭环

## 1. 版本全景

| 版本 | 主题 | 状态 |
| --- | --- | --- |
| V1.0 | Mac 客户端落地：3D 毛绒视觉、两档专注、八状态交互、右键菜单、效率工具、AI 对话 | ✅ 已发布 |
| V1.1 | 可发现性 + 对话稳定性（P0 全量、P1 全量） | ✅ 本次迭代 |
| V1.2+ | Windows 跨端适配、多情绪人设扩展深化 | 🗓 长期规划 |

## 2. P0 级迭代项（可用性测试暴露的核心痛点）

| 需求 | 问题来源 | 方案 | 落地模块 |
| --- | --- | --- | --- |
| 入口重构 · 浮动工具栏 | 59% 用户无法快速触发功能 | 悬停宠物弹出胶囊工具栏：4 个高频按钮 + 🔧 更多工具二级面板，方向自适应，光标轮询防误隐，专注时隐藏 | `floating_toolbar.py` |
| 入口重构 · 新手引导 | 新手期迷茫、右键菜单不可知 | 首次启动 4 步分步气泡 + 指引卡片，完成持久化，菜单可重看 | `onboarding.py` |
| AI 对话 · 轮次摘要压缩 | 全量历史堆积 → 上下文稀释 | 上下文 = 人设 system + 早期摘要 + 最近 6 轮全文，聊满 12 轮自动压缩 | `chat_memory.py` |
| AI 对话 · 强化人设约束 | 角色人设漂移 | 身份锁定 + 风格/规格/边界规则的 System Prompt，每次请求动态注入 | `ai_chat.py` |
| AI 对话 · 流式输出 | 等待感知差、流畅度低 | SSE 逐字上屏 + 随时停止 | `ai_chat.py` |
| AI 对话质量评估体系 | 调优缺乏量化依据 | 角色一致性 / 回答有效性 / 对话自然度 / 内容合规四维评分 | `ai_eval.py` |

## 3. P1 级优化项

| 需求 | 方案 | 落地模块 |
| --- | --- | --- |
| 视觉帧率优化 | GIF 按显示尺寸预缩放解码，paint 命中同尺寸直接绘制，免每帧 SmoothTransformation 重采样 | `config.GIF_PRESCALED_RENDER` + `pet_window.py` |
| 自定义素材上传 | 逐动作上传 GIF/MP4/MOV，复制到本地数据目录 + 映射持久化，随时恢复默认 | `pet_window.py` 自定义素材面板 |

## 4. 长期方向

- **Windows 跨端适配**：数据目录与快捷键平台化分流（代码层已预留 `platform` 分支点）；
- **多情绪 AI 人设扩展**：V1.1 已落地 3 套人设（元气/温柔/俏皮），后续扩展情绪化状态机，与宠物八状态联动。

## 5. 闭环机制

```
V1.0 可用性测试（17 样本，SUS/NPS/完成率）
        │  发现：入口 59% 失败、AI 满意度 3.4/5
        ▼
V1.1 决策迭代（P0：入口重构 + AI 对话优化；P1：帧率 + 自定义素材）
        │  落地：工具栏/引导/摘要压缩/人设约束/流式/四维评测
        ▼
复测验证（ai_eval.py 四维评分 + 下一轮可用性测试）
        │  目标：入口发现失败率 59% → <20%；AI 对话满意度 3.4 → ≥4.0
        ▼
     下一轮迭代
```
