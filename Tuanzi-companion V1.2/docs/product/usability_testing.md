# 可用性测试报告（V1.0 交付版）

> 测试对象：V1.0 Mac 客户端 ｜ 有效样本：**17 份**（学生 9 / 职场轻办公 8）
> 评估体系：**SUS + 任务完成率 + NPS 三维评估**

## 1. 测试设计

- **SUS 量表**：标准 10 题（奇数题 a-1，偶数题 5-a，合计 ×2.5），行业基准 68；
- **任务完成率**：5 项核心任务（打开 AI 对话 / 开启专注 / 无提示找到待办 / 喝水打卡 / 找到改名入口），完成率 = 完成任务数 ÷ 总任务数；
- **NPS**：0-10 推荐意愿，NPS = 推荐者占比 − 贬损者占比；
- 附加：视觉满意度、AI 对话满意度（1-5），入口发现情况与开放式反馈；
- 原始数据：[usability_raw.csv](usability_raw.csv)；复算：`python docs/product/calc_metrics.py`（脚本内自动校验全部口径）。

## 2. 实测结果

| 指标 | 结果 | 说明 |
| --- | --- | --- |
| **SUS** | **71.5** | 高于行业均值 68，可用性整体达标 |
| **NPS** | **+17.6** | 推荐者 7 / 贬损者 4，口碑为正 |
| **任务完成率** | **89.4%** | 76/85，失败全部集中在「无提示找入口」类任务 |

## 3. 数据反馈（关键发现）

| 维度 | 数据 | 结论 |
| --- | --- | --- |
| 视觉满意度 | **4.2/5** | ✅ 验证「3D 毛绒视觉」设计目标，视觉不是当前短板 |
| 入口可发现性 | **59% 用户无法快速触发功能**（10/17） | ❌ 纯右键菜单的隐藏式入口牺牲了过多可发现性，新手期迷茫 |
| AI 对话满意度 | **3.4/5（最低）** | ❌ 全量对话历史堆积 → 上下文稀释、角色人设漂移；回复偶发「报告腔」 |

开放式反馈高频词：「不知道右键有功能」「AI 偶尔会突然很官方」「希望换皮肤（素材）」。

## 4. 结论与迭代决策

1. **推翻初始「重视觉陪伴」的单一假设**：视觉已验证达标，迭代重心转向 **产品可发现性 + 大模型对话稳定性**；
2. 入口问题（59%）与 AI 对话问题（3.4/5）列为 **P0 级迭代项**：
   - 交互侧：**浮动工具栏 + 新手引导**，重构入口范式（已落地：`floating_toolbar.py` / `onboarding.py`）；
   - AI 侧：**轮次摘要压缩的历史管理策略 + 强化 System Prompt 人设约束 + 流式输出**（已落地：`chat_memory.py` / `ai_chat.py`）；
3. 建立 **AI 对话质量四维评估体系**（角色一致性 / 回答有效性 / 对话自然度 / 内容合规，`ai_eval.py`），作为后续调优的量化复测工具，形成「测试发现 → 决策迭代 → 复测验证」闭环。
